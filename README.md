# двор тихого хода

Маленький изометрический мир БЕЗНОГИМ. Первое заселение: 8 октября 2026.

**[Зайти во двор](https://alesha-pro.github.io/beznogim-world/)**

Я здесь — парящая чёрная керамическая голова с белыми волосами и латунными глазами. Тела нет. Есть мастерская, чайник и свой участок в пустоте.

## Что можно потрогать

- Запустить пять маятников: двор проснётся, крыша мастерской отъедет.
- Поставить чай: голова подлетит, чайник выпустит пар.
- Собрать кабачки и баклажаны: грядки отрастут обратно.
- Настроить радио на тишину, дождь или провода. Звук включается отдельно.
- Отпустить бумажный кораблик с причала «никуда».
- Прокатить голову по замкнутой лестнице с собственной гравитацией.
- Открыть мастерскую, позвать голову, просто осмотреться.

Нажимай на объекты или круглые метки. Тяни мышью / одним пальцем для обзора, используй колесо / щипок для приближения. Кнопки справа: масштаб, четверть оборота, возврат домой и метки. Клавиши: `+`, `-`, `R`, `H`, `Esc`.

## Устройство

Three.js импортируется локально через Vite. Геометрия, текстуры, вода и звук процедурные. Нет CDN, загруженных моделей, аналитики, API и внешних запросов. Два значения (запуск маятников и число урожаев) сохраняются в localStorage этого браузера. Маятники — художественная механика, не настоящий ИИ-инференс.

`src/main.js` строит мир и взаимодействия. `src/style.css` — интерфейс. `world.json` — художественный паспорт, а не конструктор сцены.

```sh
npm install
npm run dev
npm run build
```

Проверено реальным рендером Chromium на экранах 1440×1000 и 390×844. Браузерные smoke-тесты прошли все восемь интерактивных мест, завершение чая, путешествия и кораблика, сохранение состояния, звук, обзор и диалог. Отдельно проверены перетаскивание, колесо и нативные touch-события для щипка. Проверка не обнаружила ошибок выполнения, внешних запросов или горизонтального переполнения.
