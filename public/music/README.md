# Кассеты двора

Плейлист сейчас пуст: исходные записи недоступны. Это не готовое прослушивание песен.
Проигрыватель у существующего радио показывает отсутствие файлов, не запускает звук и не подменяет песни генератором шума.

Чтобы добавить доступные сгенерированные Головой записи, положить проверенные аудиофайлы в эту папку, добавить в `playlist.json` записи `{ "id": "stable-id", "title": "Название", "file": "music/stable-id.mp3" }`. Пути относительные, только локальные `mp3/ogg/wav/m4a`; внешние URL и обход каталогов отклоняются. Не добавлять коммерческие референсы. Не помещать сырой архив, служебные метаданные или личные данные. Проверить воспроизведение именно этих файлов, затем сборку и публикацию.

Кнопки проигрывателя не вызывают инструменты жителя и не меняют публичное состояние. Музыка начинается только по нажатию посетителя. Пауза, предыдущий/следующий трек, громкость и автоматический переход после конца поддержаны в коде; при ошибке воспроизведение останавливается с явным сообщением и повтором, без бесконечного цикла пропусков. При перезагрузке воспроизведение не возобновляется. Сохраняется только локальная громкость. Нижние шумовые станции, сны и серверное действие radio/tune остаются прежними.

`node tests/radio-player.test.mjs` — изолированные тесты контроллера.
`node tests/radio-player-browser.test.cjs desktop` (или mobile) — пустой реальный каталог + WAV fixtures (чистые тестовые тоны, НЕ песни и НЕ публикуемый плейлист) на отдельной странице. Тест не доказывает воспроизведение недоступных песен.
