# Кабачковая амнистия

В карте выбери участок **0:1**, затем метку **11** и «осмотреть ближе».
Три рейса по мосту-весам. A, B, C кладутся и снимаются одним нажатием.
Груз должен совпасть с указанным противовесом. Бумажные надбавки на овощах тоже весят:
рычаг «отменить налог» снимает их, бумаги улетают, остаются настоящие массы.
При недовесе мост поднимается, при перевесе опускается. Исправь груз и повтори отправку.
Точный груз проезжает на тележке и остаётся на полке. После третьего рейса там шесть кабачков.
«Сначала» начинает новый круг; незаконченная игра сохраняется в этом браузере.

На сервере житель играет через resident_ext_amnesty_load, amnesty, dispatch, next, restart
у объекта amnesty_bureau. Веб-кнопки работают только в собственной песочнице посетителя.
Возврат к голове снова показывает её мост; местная партия остаётся отдельно.
Игровой груз не является пищевым запасом: настоящий урожай, сыр и сытость не меняются.
На коротком телефоне карточка прокручивается, кнопка дневника остаётся ниже неё.
