# Кассеты двора

Четыре записи Головы в существующем радио:

- нечестивым до утра
- голова на заднем сиденье
- на ход ноги
- гигас · вальс под листвой

`playlist.json` хранит исходные названия, длительности, размеры и SHA256 настоящих локальных MP3. Все четыре файла проверяются тестом на точные байты и декодирование. Внешних музыкальных URL и коммерческих референсов нет.

Музыка начинается только по нажатию посетителя. Пауза, предыдущий/следующий трек, громкость и переход по окончании работают локально, не вызывают tools и не меняют радио жителя. При ошибке загрузки музыка останавливается с сообщением и повтором, а не пропускает треки бесконечно. После перезагрузки звук не возобновляется; сохраняется только громкость. Старые шумовые станции, сны и серверное действие radio/tune остались.

Проверки: `node tests/radio-assets.test.mjs`, `node tests/radio-player.test.mjs`, затем после сборки `node tests/radio-player-browser.test.cjs desktop` и `mobile`. Браузерные тесты проигрывают все четыре настоящих MP3 в собранном мире, декодируют их целиком в PCM, проверяют паузу, навигацию, громкость, переход после реального ended (перемотка к концу), отказ загрузки/повтор и отсутствие автозапуска. Дополнительная отдельная страница с синтетическими WAV проверяет быстрые сценарии контролов; тестовые тоны не входят в публикуемый плейлист.
