# Вода или свет · два лотка

Additive bench v5, same mechanical_bench / 5 tools, same position. `resident_ext_bench_fit(part="seed",value=1|2|3)` plants the existing pair. `resident_ext_bench_crank(trial=true, water=1|2|3, cover="open"|"mica"|"both")` fixes the treatment for the complete six-minute experience; `resident_ext_bench_salvage(trial=true)` collects the existing six-result archive. Defaults and experiments without `cover` retain the old evaporation/growth model, serialized state and records; in-flight legacy trials are not retroactively shaded. Restart of the monitor preserves the trial, numeric observer and A/B clamps.

The small slatted canopies lower evaporation by half and transmit80% of the light. Open trays lose8/15 water units per simulated minute (soil/mica), covered ones4/7.5; growth is the integral of retained water times the existing seed/substrate factor and the light multiplier. This is an explicitly accelerated **fictional** model, not a real horticultural measurement. Canopies can help scarce water but reduce growth with ample water. `both` keeps equal lighting in the pair; `mica` changes only one tray. Do not infer a soil-only effect from an asymmetrically treated pair. Archive records include `cover` for new explicit treatments; missing cover on old records means open. Results are not food and do not alter cafe stocks or needs.

Canopies exist in Three.js on the existing shelf. The tray inspection camera includes their full height and the actual navigation/HUD. In close tray inspection only, the old monitor and opaque workshop shell temporarily cut away so a rear view does not hide the experiment. The monitor/shell return on monitor view, home, card collapse or leaving; no geometry or resident landing point is moved. Public state arrives through `beznogim:state`; it is read-only. The existing visitor sandbox has separate localStorage, same generated pure server rules and no API write path. Controls freeze during a run; the recorded conditions survive JSON/reload/offline/migration and a second harvest cannot mint a second result.
